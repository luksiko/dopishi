# Проверка подсказок: этапы 1–3, 21 октября 2026

40 синтетических примеров: 20 RU и 20 EN. Из них 38 содержательных и два контроля пустого ввода. Есть переписка, технические задачи, длинный контекст, незавершённые слова, emoji и вставка перед существующим текстом. Личная история ввода не использовалась.

## Результат одного рабочего цикла

| Вариант | Полезные / 38 | Слабые / 38 | Показано / 40 | Медиана | p95 |
|---|---:|---:|---:|---:|---:|
| Qwen 2.5 0.5B, исходная реализация | 16 | 6 | 36 | 0,075 с | 0,184 с |
| Qwen 2.5 0.5B, новая реализация | 16 | 4 | 24 | 0,050 с | 0,083 с |
| Gemma 4 E2B, новая реализация | 24 | 5 | 32 | 0,639 с | 0,712 с |

Оценка выполнена Codex при просмотре результата вместе с исходной фразой. Это субъективная диагностическая оценка, а не независимая человеческая экспертиза. Баллы каждого примера — в `review.json`: 2 — полезное продолжение, 1 — слабое, 0 — неправильное или отсутствующее. Пустые контроли исключены из знаменателя. Модели не сравниваются по точному совпадению с одним эталоном.

Примеры:

- «Если интернет недоступен, изменения сохраняются локально и отправляются после …»: исходный Qwen — «сообщения.»; Gemma — «восстановления соединения.».
- «Я добавил индекс, чтобы запрос к базе выполнялся …»: исходный Qwen — «Имейте индекс, чтобы запрос»; Gemma — «быстрее.».
- «Спасибо за помощь! Теперь всё …»: исходный Qwen — «не будет сложностей.»; Gemma — «работает!».

Новый промпт сам по себе не увеличил число полезных ответов Qwen 0.5B. Основной прирост в этом наборе дала Gemma. Ошибки остаются: например, Gemma продолжила фразу о закрытии окна словами «not a valid URL». Два русских незавершённых слова не получили подсказки.

## Что изменено

- AX-контекст для AI расширен с 200 до 2048 UTF-16 единиц в каждую сторону. Модели с chat template получают до 512 символов после каретки. Учитывается выделение, проверяются диапазоны и неизменность поля после инференса. При недоступном тексте одно-два последних слова больше не подменяют контекст.
- Для GGUF с собственным `tokenizer.chat_template` используется `/apply-template` из llama-server и заполнение начала ответа текущим абзацем. Общих вручную заданных ChatML-шаблонов и демонстрационных историй больше нет.
- GGUF без chat template получает сырой префикс. Конечные пробелы убраны перед токенизацией, разделитель согласуется с уже введённым текстом. Для незавершённого слова генерация начинается от границы слова; результат принимается только при совпадении набранного префикса.
- Убраны HTML-теги и служебные токены, разрешены английские технические термины в русском тексте. Бюджет генерации ограничен, таймауты запросов увеличены до 3/4 секунд, чтение метаданных вынесено с главного потока. Назначения клавиш не менялись в коде.

## Ограничения и воспроизведение

Gemma — уже имевшийся стандартный `gemma-4-E2B-i1-Q4_K_M.gguf` (около 3,2 ГБ) в каталоге моделей Cotypist. Это базовый checkpoint без chat template. Он не обрабатывает пользовательские системные инструкции; при наличии текста справа от каретки приложение консервативно отказывается от AI-вставки. Файл Cotypist `gemma-4-E2B-Q4_C.gguf` (2,8 ГБ) имеет другой заголовок и в этом тесте не использовался. Эквивалентность его весам или обработке Cotypist не установлена.

Первый вызов Gemma занял 3,26 с, включая обнаружение формата GGUF; медиана характеризует последующие вызовы. Оба сервера были загружены заранее. Исходный Qwen работал с окном сервера 2048 токенов, Gemma — 4096; запросы выполнялись последовательно. Старый клиент использовал прежние параметры, новый — temperature 0.2 и seed 42. Это сравнение конечного поведения до/после, не контролируемый тест одних весов. Повторный прогон может дать другие ответы.

`cases.json` содержит входы; `baseline-qwen.json` сохранён до изменения Swift-клиента; `updated-*.json` получены из финального клиента. Скрипт компилирует настоящий `AIInferenceEngine.swift` во временный CLI, подставляя только адрес уже работающего сервера и путь модели. Настройки приложения не изменяет, сервер сам не запускает:

```sh
python3 scripts/evaluate-completions.py --port 19345 --model '/path/model.gguf' --output /tmp/results.json
```

Флаг `--baseline` воспроизводит только прежнее ограничение контекста; для воспроизведения всего старого клиента нужна его исходная версия. Время не включает debounce и отображение overlay. AX-получение контекста, физический ввод и Tab этим CLI не проверяются. Полный XCTest-набор проверен отдельно: 365 тестов, 0 ошибок. Повторная физическая проверка установленной версии в Codex пока не выполнена.

Universal Release установлен полным подписанным bundle в `/Applications/LangSwitcher.app`, прежняя версия сохранена установщиком в ZIP. В настройках выбрана совместимая Gemma через существующий пункт custom GGUF. Подтверждены запуск этой модели, HTTP health 200, Accessibility trust и запуск мониторинга клавиш. Tab / Shift+Tab сохранены. Модель используется по её существующему пути в каталоге Cotypist; удаление этого файла потребует выбрать модель заново. Логи цикла и резервная копия настроек находятся в `/tmp/langswitcher-verification/cycle-1-3/`. Исходно работавший Cotypist оставлен запущенным; физическое сравнение требует включать подсказки приложений по очереди.
