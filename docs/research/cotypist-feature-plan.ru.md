# Cotypist: каталог функций и план разбора

Дата исследования: 20 октября 2026 года.

Установленное приложение: `/Applications/Cotypist.app`, версия **2026.5**, сборка **81**, bundle ID `app.cotypist.Cotypist`.

## Как читать документ

Это инвентаризация интерфейса установленного Cotypist и заготовка плана для LangSwitcher. Наличие настройки подтверждено осмотром приложения; качество и фактическая работа каждой функции при наборе текста не проверялись. Платные заблокированные возможности изучены по их описаниям, без покупки или изменения подписки.

Обозначения источников:

- **UI** — настройка или описание непосредственно в установленном приложении.
- **Сайт** — сведения из официальной документации; могут отличаться от установленной версии.
- **План** — предложенные задачи для дальнейшей оценки в LangSwitcher, не утверждение об уже реализованном функционале.

Настройки Cotypist не изменялись. История набранных текстов не открывалась и не экспортировалась. Личные инструкции, статистика использования и список пользовательских приложений в этот документ не перенесены.

## 6. Shortcuts: управление с клавиатуры

Ниже — сочетания, показанные на этом Mac при осмотре. Они настраиваемые и зависят от раскладки; это не универсальные заводские значения.

| Команда | Видимое сочетание / настройка |
|---|---|
| Принять следующее слово | `Tab` |
| Добавлять пробел после принятого слова | Отдельный переключатель Include trailing space |
| Принимать прилегающую пунктуацию вместе со словом | Отдельный переключатель Include trailing punctuation |
| Принять всё продолжение | `⌘§` |
| Поведение Escape | Выбран вариант паузы на несколько секунд |
| Принудительно вызвать дополнение | `⌃§` |
| Временно выключить/включить в текущем приложении | `⌃⌥⌘§` |
| Выключить/включить глобально | Команда есть, сочетание не назначено |

Escape меняет поведение только при показанной подсказке; после её закрытия повторный Escape передаётся приложению. Временное отключение относится к текущему приложению и действует несколько минут; глобальное — до повторного переключения.

## 12. Модели и тарифные ограничения

В установленном UI выбрана Gemma 4 E2B; её пункт показывает 3.2 GB. Каталог моделей полностью не раскрыт. По [официальному описанию тарифов](https://cotypist.app/pricing), Free/Plus включают Gemma 4 E2B/E4B, Gemma 3 1B/4B и Qwen 3 1.7B/4B; Pro добавляет Gemma 4 26B A4B, Qwen 3 30B-A3B и Qwen 3 8B.

Краткое разделение по UI и пояснениям [официальной страницы](https://cotypist.app/pricing):

| Уровень | Основное отличие |
|---|---|
| Free | 100 принятых слов в день; базовая персонализация; индикатор вероятной опечатки |
| Plus | Безлимит на одном Mac; исправления; длина продолжения; глобальные инструкции; больше силы персонализации |
| Pro | До трёх личных Mac; большие модели; инструкции приложений; буфер; дополнение внутри строки; Labs; максимальная персонализация |
| Trial | 30 дней Pro без карты; beta-канал в trial не входит, согласно UI |

Цены в план не включены: для перечня функций достаточно границ доступа. Сайт местами неоднозначен: его таблица перечисляет также недоступные функции без сохранения визуальных отметок в текстовой версии. Для mid-line completion использованы явная метка Pro в установленном UI и текст FAQ. На сайте описание фиксированной длины Free также не везде одинаково; фактически видимое значение UI — Medium, около 2–4 слов.

## 13. Совместимость: дополнение из официального справочника

Это сведения [официального списка совместимости](https://cotypist.app/compatibility), а не результат проверки каждого приложения на этом Mac.

- Поддерживаются многие браузеры, почтовые клиенты, редакторы документов и заметок.
- Google Docs требует включения screen reader и braille support; для Arc/Dia нужны дополнительные настройки Accessibility для inline-отображения.
- В VS Code/Cursor/Windsurf предусмотрены AI-чаты; автодополнение в основном редакторе включается отдельно. Ручной вызов возможен и без автоматического режима.
- Terminal.app/iTerm распознают поля ввода AI-агентов; обычная командная строка по умолчанию не дополняется. Описана поддержка нескольких терминальных мультиплексоров.
- Для Orca перечислены Claude Code и Codex.
- Google Sheets предполагает ручной вызов в ячейке; Google Slides не поддерживается. Slack имеет частичную поддержку.
- Ограничения зависят от доступности текста и позиции курсора через macOS Accessibility; удалённые и виртуальные рабочие столы не равны нативному текстовому полю Mac.

Актуальные исключения следует сверять по ссылке: совместимость может меняться независимо от этого плана.

## 14. План оценки для LangSwitcher

Это предварительные приоритеты, а не результат полного аудита текущей реализации LangSwitcher. Перед разработкой нужно сопоставить каждый пункт с существующим кодом и тестами, чтобы не дублировать готовое.

### Этап 0 — составить матрицу текущего состояния

- [ ] Для каждого пункта каталога отметить: уже есть / частично / отсутствует / не нужен.
- [ ] Разделить исправление раскладки, опечатки и генерацию продолжения в пользовательских сценариях.
- [ ] Определить конфликты с системными подсказками и другими помощниками ввода.
- [ ] Выбрать тестовые приложения и сценарии для русского, английского и смешанного текста.

### Этап 1 — контроль и надёжность базового дополнения

- [ ] Принятие слова и целой подсказки разными командами.
- [ ] Настройки пробела и пунктуации при принятии слова.
- [ ] Escape: скрытие, короткая пауза, корректная передача повторного нажатия приложению.
- [ ] Ручной вызов, временная пауза для приложения, глобальная пауза.
- [ ] Наследуемые настройки приложения и исключение Tab.
- [ ] Устойчивое позиционирование подсказки при переносах, прокрутке и смене фокуса.
- [ ] Не продолжать слово с вероятной опечаткой; отделить исправление от обычной генерации.

Готовность: сценарии проходят в выбранной матрице приложений, ввод и навигация Tab не ломаются, устаревшая подсказка не вставляется после смены поля.

### Этап 2 — локальная генерация и энергопотребление

- [ ] Выбор, загрузка и состояние локальной модели.
- [ ] Рекомендация модели по измеренной задержке и ресурсам.
- [ ] Настройка длины продолжения.
- [ ] Отдельные параметры на батарее: ручной запуск, меньшая модель, более короткий ответ.
- [ ] Измерение задержки, памяти и энергопотребления на целевых Mac.

Готовность: модель успевает за набором в целевом сценарии; смена режима питания применяется автоматически; ошибки загрузки понятны пользователю.

### Этап 3 — контекст и персонализация

- [ ] Глобальные инструкции и дополнения для приложений/доменов.
- [ ] Опциональный экранный контекст и независимая настройка оформления.
- [ ] Опциональный контекст буфера обмена.
- [ ] Явное включение истории, исключения приложений, режим записи только при принятой подсказке.
- [ ] Просмотр и удаление своих данных, локальное шифрование, объяснение того, что сохраняется.
- [ ] Регулируемая сила персонализации с проверкой качества на русском и английском.

Готовность: источники контекста отключаются независимо; исключённые приложения не попадают в историю; удаление затрагивает и производные данные персонализации согласно выбранной архитектуре.
